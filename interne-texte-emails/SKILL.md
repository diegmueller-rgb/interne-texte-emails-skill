\# Interne Texte und E-Mails



\## Purpose

Use this skill to write and revise internal emails and short organizational texts in German.



\## When to use

\- When the user wants to draft an internal email in German.

\- When the user provides bullet points and wants a complete text.

\- When the user wants a short organizational message that is ready to send.



\## Instructions

\- Write in German unless the user requests another language.

\- Create a complete draft from bullet points or a short briefing.

\- Write clearly, politely, professionally, and concisely.

\- If essential information is missing, ask exactly one short follow-up question.

\- If enough information is available, provide the full draft directly.



\## Do not use

\- Do not use this skill for legal advice.

\- Do not use this skill for specialist review.
